1. 한 줄 요약

Sermine은 계정이 없고, 영상과 대본을 개발자 서버로 보내지 않습니다. 영상 처리는 모두 사용자의 Mac 안에서 이루어집니다.

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 계정 정보 (회원가입이 없습니다)
  • 사용 기록, 분석 정보, 광고 식별자 (분석·광고 도구를 사용하지 않습니다)
  • 사용자의 영상, 이미지, 대본, 인물 정보를 개발자가 받거나 저장하는 일

3. 영상은 어디서 처리되나요

사용자가 연 영상은 이 Mac 안에서만 처리됩니다. 장면과 대사를 읽는 데에는 Apple의 문자 인식(Vision)과, Mac에서 직접 실행되는 AI 모델(MLX 기반 Qwen2-VL)을 사용합니다. 영상 속 소리를 글로 옮기는 "소리 듣기" 기능은 Apple의 음성 인식(Speech)과, Mac에서 직접 실행되는 음성 인식 모델(Whisper, WhisperKit 기반)을 함께 사용하며, 소리는 이 Mac 안에서 처리됩니다. 대본을 만들 때 같은 목소리를 묶어 말한 사람 후보를 제안하는 화자 구분 기능은 Mac에서 직접 실행되는 화자 구분 모델(FluidAudio 기반)을 사용하며, 영상의 소리는 이 Mac 안에서 처리됩니다. 영상 내용은 인터넷으로 전송되지 않습니다. 외국어 대사를 한글로 옮기는 번역은 Apple의 번역 기능(Translation)을 사용하며, Mac 안의 번역 모델로 처리됩니다.

4. 인터넷 연결이 필요한 경우

Sermine이 인터넷에 연결하는 경우는 아래 네 가지뿐입니다. 네 경우 모두 사용자의 영상이나 대본이 전송되지는 않습니다.

  1. AI 모델 내려받기: 처음 사용할 때 AI 모델 파일(2B 모델 약 1.3GB, 7B 모델 약 4.7GB)을 Hugging Face(huggingface.co)에서 내려받습니다. 이 과정에서 사용자의 IP 주소 등 접속 정보가 Hugging Face에 전달될 수 있으며, 그 처리에는 Hugging Face의 개인정보 처리방침이 적용됩니다. 한 번 받은 뒤에는 모델을 사용할 때 인터넷이 필요하지 않습니다.
  2. Apple 언어 팩 (번역, 음성 인식): 번역과 음성 인식은 Apple이 제공하는 기능을 사용합니다. 처음 쓰는 언어에서는 필요한 번역 언어 팩이나 음성 인식 언어 모델을 Apple이 제공하는 방식으로 내려받을 수 있습니다. 이 경우 Apple의 개인정보 처리방침이 적용됩니다.
  3. Whisper 음성 인식 모델 내려받기: 소리를 더 정확히 글로 옮기는 데 쓰는 Whisper 모델 파일(약 626MB)을 처음 사용할 때 Hugging Face(huggingface.co)에서 내려받습니다. 이 과정에서 사용자의 IP 주소 등 접속 정보가 Hugging Face에 전달될 수 있으며, 그 처리에는 Hugging Face의 개인정보 처리방침이 적용됩니다. 한 번 받은 뒤에는 인터넷이 필요하지 않고, 영상이나 소리는 전송되지 않습니다.
  4. 화자 구분 모델 내려받기: 말한 사람 후보를 제안하는 데 쓰는 화자 구분 모델 파일(약 22MB)을 처음 사용할 때 Hugging Face(huggingface.co)에서 내려받습니다. 이 과정에서 사용자의 IP 주소 등 접속 정보가 Hugging Face에 전달될 수 있으며, 그 처리에는 Hugging Face의 개인정보 처리방침이 적용됩니다. 한 번 받은 뒤에는 인터넷이 필요하지 않고, 영상이나 소리는 전송되지 않습니다.

5. 기기에 저장되는 정보

이 정보들은 개발자에게 전송되지 않습니다.

  • 대본과 프로젝트 파일은 사용자의 Mac 안(앱의 저장 공간)에 저장됩니다.
  • 글꼴, 화면 모드 같은 설정은 Mac 안에 저장됩니다.
  • 사용자가 직접 고른 위치로 내보낸 파일은 사용자가 관리합니다.
  • 내려받은 AI 모델 파일은 Mac 안의 저장 공간에 보관됩니다.

6. 삭제

앱을 삭제하면 앱이 만든 설정은 함께 지워집니다. 대본 프로젝트와 내려받은 모델 파일은 Mac의 앱 저장 공간에 남을 수 있으므로, 완전히 지우려면 해당 폴더를 직접 삭제하세요. 내보낸 파일은 사용자가 직접 삭제합니다.

7. 제3자 소프트웨어

Sermine은 오픈소스 소프트웨어와 AI 모델을 사용합니다. 목록과 라이선스 전문은 앱의 설정에서 "오픈소스 라이선스"를 선택하면 볼 수 있습니다.
